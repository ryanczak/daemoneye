# Bug 3 on phase-12: the budget bar's percentage is cut off

**Severity:** major
**Status:** open
**Filed:** 2026-10-24

## What's wrong
`draw` passes `inner_width(rects.budget)` as `budget_bar`'s `width`, the
number of cells between the brackets. The bar string is then that width
plus the two brackets plus ` NN%`, wider than the panel, so the `] NN%`
tail is clipped. On an 80-column screen the inner width is 78 and the
string is 84 characters long. `screen_colours_the_budget_bar` checks only
cell glyphs and colour, so it passes with the percentage missing.

## What should happen
Spec item 3: the live Budget panel shows the whole bar, `[…] NN%`, as its
last line.

## Root cause
The cell count passed to `budget_bar` does not leave room for the brackets
and the percentage.

## Definition of done
- [ ] `screen_shows_the_budget_percentage` passes: with spend 8.5 and cap 10
      the drawn buffer holds `85%` at 80×24 and at 120×40.
