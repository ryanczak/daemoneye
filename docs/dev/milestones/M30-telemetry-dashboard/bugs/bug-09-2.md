# Bug 2 on phase-09: the TUI's Shells body re-implements `shells_text`

**Severity:** minor
**Status:** open
**Filed:** 2026-10-22

## What's wrong

`draw` in `src/cli/commands/top_tui.rs` builds the Shells body with its own
`match` on `ShellsPanel` and its own row `format!`, which copies
`shells_text` in `src/cli/commands/top.rs`. `shells_text` is private, so
the copy compiles, but the two will drift: a change to the `--once`
wording will not reach the live screen.

## What should happen

Phase-09 Spec item 3: "Each block's body is the matching `*_text`
output." The Shells block calls `shells_text`, as the Runs, Budget and
Activity blocks call theirs.

## Root cause

`shells_text` is private to `top.rs`, and the TUI copied it instead of
widening its visibility.

## Definition of done

- [ ] `grep -c 'unwrap_or("-")' src/cli/commands/top_tui.rs` ⇒ `0`. It
      reads `2` against the current tree (verified 2026-10-22).
- [ ] `shells_text` is `pub(crate)` (or `pub`) and `draw` calls it.
