# Bug 1 on phase-02: the status bar measures its hint in chars, so a `⚡` hint overflows the pane by one column

**Severity:** minor
**Status:** open
**Filed:** 2026-11-02

## What's wrong

`status_bar_line` (`src/cli/render_ratatui.rs`) decides whether the hint fits,
and how wide the gap before it is, from `chars().count()` of the left part
and of `status.approval_hint`. The hint `SessionApproval::hint()` returns
whenever any approval is active starts with `⚡` (U+26A1 HIGH VOLTAGE SIGN),
whose East Asian Width is `W`: it occupies **two** terminal columns
(`unicode-width` gives it 2, as ratatui's `Span::width` / `Line::width` do).
So when the left part and the hint fit by char count, the built line is one
column wider than the area, and the `Paragraph` clips its last cell: on an
80-column pane the bar ends `… Ctrl+C revoke`. At the boundary width (left +
hint + 1 chars) the hint is kept although it does not fit.

The tests could not see it: `status_bar_drops_hint_before_clipping` and the
other width assertions in `src/cli/render_ratatui_tests.rs` measure with
`text.chars().count()`, which counts `⚡` as one.

## What should happen

Phase-02 § Behaviour: "the bar never exceeds the area's width. When the left
part and the hint do not both fit with at least one space between them, the
hint is dropped whole". Width means terminal columns. With the `⚡` hint at
a width where both fit, the line's display width equals the area's width and
the hint's last character is on screen; one column narrower than that, the
hint is dropped and the left part is intact.

## Root cause

Display width is measured as a char count in `status_bar_line` (the
`left_width`, `hint_width`, `fits_with_hint` and gap arithmetic) and in the
tests' width assertions.

- [ ] `status_bar_fits_a_wide_hint_exactly` (new) passes: with the hint

      width and the text ends `revokes`; (b) one column narrower, the hint is
      absent and the left part ends `up 3m 2s`. It fails on the current tree
      at (a).
- [ ] Every width assertion in the `status_bar_` tests measures display width
