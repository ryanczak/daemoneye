# Bug 2 on phase-04: an existing read test and a doc comment were deleted

**Severity:** major
**Status:** open
**Filed:** 2026-11-26

## What's wrong

The phase's migration of `with_home` in
`src/daemon/executor/file_ops/read_tests.rs` deleted two unrelated pieces of
the file:

1. **The test `read_file_default_reads_from_start`**, which checked that a
   plain `run_read_file` returns the file from its first line. Nothing
   replaced it. `grep -c 'fn read_file_default_reads_from_start'
   src/daemon/executor/file_ops/read_tests.rs` prints `0`.
2. **The first five lines of the doc comment on
   `build_remote_read_cmd_is_unchanged`**, starting `/// Preservation: the
   command the new transport runs is byte-for-byte the`. Only its last
   line, `/// remote read return the whole screen.`, is left. That line is
   now a fragment.

The phase authorized neither change. Its closed file list allowed new tests
in `read_tests.rs`, not removing existing ones.

## What should happen

Both are restored as they were at `fc832c51`, the phase's parent commit. The
test is adapted only as far as the new `with_home` helper requires, the
same way its sibling tests were migrated (`with_home_set(&tmp).await`).

## Root cause

A broad rewrite of the top of the file while migrating the `with_home`
callers.

## Definition of done

- [ ] `read_file_default_reads_from_start` exists and passes.
- [ ] `grep -c 'Preservation: the command the new transport runs is byte-for-byte the' src/daemon/executor/file_ops/read_tests.rs`
      prints `1`. It prints `0` today.
