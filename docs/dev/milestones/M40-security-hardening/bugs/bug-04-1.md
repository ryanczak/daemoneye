# Bug 1 on phase-04: `resolve_path_for_guard` drops the first missing component

**Severity:** major
**Status:** open
**Filed:** 2026-11-26

## What's wrong

When the path does not exist, `resolve_path_for_guard`
(`src/daemon/executor/file_ops/mod.rs`) re-joins one component too few. It
drops the **first** missing component, the one directly under the deepest
existing ancestor.

The reviewer ran it with `lnk → <tmp>/real` (`real` exists):

| path | resolved | should be |
|---|---|---|
| `lnk/f.txt` | `<real>` | `<real>/f.txt` |
| `lnk/a/f.txt` | `<real>/f.txt` | `<real>/a/f.txt` |
| `lnk/a/b/f.txt` | `<real>/b/f.txt` | `<real>/a/b/f.txt` |

The first row is a **regression**: the parent-only code this phase replaced
resolved it correctly. A guard that compares against a resolved path that
names the wrong file can pass or refuse the wrong path. One example: a
missing chain that starts at `~/.daemoneye` itself resolves to `$HOME/…`,
outside both guard roots.

`path_guard_resolves_through_missing_dirs_under_a_symlink` did not catch
this, because it asserts only `starts_with`.

## What should happen

The phase spec, Statement of work item 1: canonicalize the deepest existing
ancestor and "join the missing components back onto it, in their original
order". A path that does not exist resolves to
`canonicalize(deepest existing ancestor)` joined with **every** component
below that ancestor. An existing path resolves exactly as `canonicalize`
does.

## Root cause

In the missing branch, the code counts the ancestors that fail to
canonicalize. That count already includes the path itself, and it equals
the number of missing components. The code then takes `count - 1`
components from the end, which loses one.

## Definition of done

- [ ] `path_guard_keeps_every_missing_component` passes, in `read_tests.rs`.
      With `lnk → <tmp>/real`, it asserts **equality** (not `starts_with`)
      of `resolve_path_for_guard` against `canonicalize(real).join(rel)`,
      for each `rel` in `f.txt`, `a/f.txt` and `a/b/f.txt`. It fails today
      on all three.
- [ ] Every phase-04 test still passes.
